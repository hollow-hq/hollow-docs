## Syntax Conventions

In our command reference pages, command signatures use standard notation:
- `<argument>` — Required parameter.
- `[argument]` — Optional parameter.
- `[member | user]` — Parameter accepts a user mention (`@voby`), user tag, or 18-digit Discord snowflake ID.
- `[amount = 15]` — Optional parameter with a default value if omitted.
