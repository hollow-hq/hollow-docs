# Welcome to Hollow

**Hollow** is Discord's premier all-in-one guild bot designed for communities of every scale. Built with low-latency shard routing, native slash commands, responsive text commands, and deep Discord feature integration, Hollow equips server administrators with enterprise-grade moderation, automated join protection, temporary voice channels, rich embed scripting, and entertainment modules.

## Command Invocation Styles

Hollow supports two invocation styles interchangeably:

1. **Discord Slash Commands (`/`):** Native autocomplete, typed parameters, and argument validation directly in your Discord client.
2. **Prefix Text Commands (Default `,`):** Fast, classic Discord bot commands. You can change the guild prefix using `,prefix add <symbol>` or assign your own personal prefix with `,prefix self add <symbol>`. Mentioning the bot (`@Hollow`) also works as a universal prefix.

<Note>
  Hollow respects strict Discord role hierarchy. Make sure the `Hollow` role is positioned above any member roles it is expected to manage or moderate.
</Note>
